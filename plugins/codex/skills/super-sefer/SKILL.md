# סופר-ספר ל-Codex

## סופר-ספר — מבט על
תהליך מקצה לקצה: 1 כתיבה בקול המשתמש · 2 עריכה ספרותית · 3 עריכה לשונית · 4 הגהה · 5 עימוד · 6 הגהה אחרי עימוד · 7 כריכה · 8 שפה גרפית ואיורים · 9 ייצוא PDF.

התחילו תמיד ב: `sofer-sefer status` ו-`sofer-sefer chapters`. לפי המצב הציעו את השלב הבא וקראו לכישור המתאים:
sefer-write · sefer-lit-edit · sefer-ling-edit · sefer-proof · sefer-layout · sefer-postproof · sefer-cover · sefer-visual · sefer-export.

פרויקט חדש: `sofer-sefer new <תיקייה> --title "…" --author "…"`. ייבוא כתב־יד: `sofer-sefer import file.md --split`.
האפליקציה הגרפית: `sofer-sefer gui`.
## עבודה עם הפרויקט
- הפרויקט הוא תיקייה עם `ספר.json` ופרקים ב-`chapters/`. הריצו את הפקודות מתוך התיקייה, או הוסיפו `--project <תיקייה>`.
- אם הפקודה `sofer-sefer` לא נמצאה: `sofer-sefer setup` (או פתחו את אפליקציית סופר-ספר פעם אחת).
- כל כתיבה לפרק שומרת גרסה קודמת ב-`.history/`. לעולם אל תערכו קבצי `chapters/*.md` ישירות — השתמשו ב-`sofer-sefer apply`.
- שמרו על קולו של המחבר/ת. התערבות מינימלית. אל תמציאו עובדות.
- ענו למשתמש בעברית.

## שלב 1 — כתיבה בקול המשתמש
1. `sofer-sefer style analyze` ואז `sofer-sefer style show` — הפרופיל הסגנוני (עדכנו אחרי כל פרק חדש שהמשתמש הקליד).
2. `sofer-sefer prompt write <פרק> --brief "…" --words 1200` — מדפיס את הפרומפט המלא (מחקר כתיבה + הקשר + פרופיל + סוף הפרק הקודם). **בצעו אותו בעצמכם**: כתבו את הפרק לפי ההוראות והפורמט שבו.
3. שמרו: `sofer-sefer apply write <פרק> --file draft.md` (או stdin).
4. הציגו למשתמש וקבלו אישור לפני שממשיכים. אפשר גם הרצה אוטומטית: `sofer-sefer write <פרק> --brief … --apply`.
אל תנחשו קול כשאין מספיק טקסט — בקשו מהמשתמש לכתוב פרק/שניים. תוכן שנוצר ע"י AI לא נחשב קול המשתמש.
## עבודה עם הפרויקט

3. לאחר אישור: `sofer-sefer apply lit <פרק> --file revised.md`.
התערבות מינימלית; אל תשכתבו משפט שעובד.

## שלב 4 — הגהה
1. `sofer-sefer proof lint all` — דוח תו־תו. `sofer-sefer proof lint all --fix` — תיקון בטוח אוטומטי (בטוח: רווחים, מירכאות/גרשיים, מקפים, שלוש נקודות, אותיות סופיות).
2. מעבר מודל: `sofer-sefer proof ai <פרק>` (אוטומטי), או ידנית: `sofer-sefer prompt proof <פרק> --window N` לכל חלון, והחילו תיקוני find→replace ייחודיים בלבד.
3. חזרו על lint עד שהוא נקי (למעט info).
אין שינויי סגנון בהגהה. ספק → שאלה למחבר/ת.

## שלב 5 — עימוד
1. `sofer-sefer layout sizes` ו-`sofer-sefer layout recommend --trim a5 --pages 220` — בחרו גודל לפי ז'אנר (פרוזה 14×21/A5; עיון רויאל; ילדים ריבוע; כיס).
2. `sofer-sefer layout set trim=a5 fontBody="Frank Ruhl Libre" fontSize=11.5 chapterStart=recto folio=center …`; גופנים: `sofer-sefer layout fonts`.
3. `sofer-sefer layout build` — מפיק PDF (עמודים ריקים לפתיחת פרקים בעמוד שמאלי, תוכן עניינים אוטומטי, מספור, כותרות ריצה, ריפוד ל-4).
4. בדקו תוצאה בעין (המירו עמודים לתמונה אם אפשר) והתאימו.
ידע טיפוגרפי: `knowledge/05-typography-layout.md` — בעברית אין נטייה; יישור דו־צדדי מצריך שורה ≥45 תווים.

## שלב 7 — כריכה
1. `sofer-sefer prompt cover` — הפיקו 3 קונספטים (JSON) ושמרו: `sofer-sefer apply cover --file concepts.json`; בחירה: `sofer-sefer cover use 1`.
2. התאמות: `sofer-sefer cover set layout=fullbleed palette.bg=#16222e title="…" tagline="…" blurb="…" isbn=978…`.
3. תמונה: `sofer-sefer illustrate cover --prompt "…"` (Codex, מודל gpt-image) — קחו בחשבון אזהרת DPI.
4. `sofer-sefer cover build` (פריסה: גב·שדרה·חזית; `--mode pages` לשני עמודים) ו-`sofer-sefer cover geometry`.
הכריכה נבנית אחרי נעילת מספר העמודים. ידע: `knowledge/07-cover-design.md`.

## שלב 8 — שפה גרפית ואיורים
1. `sofer-sefer visual bible --brief "…"` (או `sofer-sefer prompt visual` ו-`sofer-sefer apply visual --file bible.json`).
2. איור לפרק: `sofer-sefer illustrate <פרק>` — מתכנן סצנה, מצרף stylePrefix מילה־במילה ותמונת ייחוס, ומפעיל Codex (`image_gen`) דרך מנוי המשתמש.
3. התמונה הראשונה הופכת לעוגן סגנון; שמרו עקביות.
יצירה ישירה: `sofer-sefer image --prompt "…" --out file.png`. אם משתמשים ב-codex-plugin-cc מתוך Claude Code, אפשר גם `/codex:rescue` עם פרומפט תמונה — אך העדיפו את ה-CLI שמצרף ייחוס וסגנון.

## שלב 9 — ייצוא
