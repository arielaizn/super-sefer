# הכנה להדפסה וייצוא

## שני קבצים
1. **פנים הספר (interior)** — PDF אחד, מעמוד פתיחה (שער חצי) עד העמוד האחרון: שער, זכויות, הקדשה, תוכן, מבוא, פרקים, אחרית דבר. גודל עמוד = גודל חיתוך (trim). גופנים משובצים (embedded). עמודי מראה (spreads) לא; עמוד־עמוד.
2. **כריכה (cover)** — PDF אחד שמכיל חזית וגב. פריסה מלאה: `bleed + גב + שדרה + חזית + bleed` ברוחב; `bleed + גובה + bleed` בגובה. ניתן גם עמוד־לעמוד (חזית, גב) לתצוגה מקדימה בחנויות.

## בחירת גודל
- בחרו לפי ז׳אנר וקהל; אל תתחילו מהדפוס. אחרי שנבחר — השוליים וגודל הגופן נגזרים מהגודל.
- מספר עמודים משפיע על: עובי שדרה, שולי שדרה (gutter), מחיר.
- מגבלות הדפסה לפי דרישה (KDP וכד׳): גודל, מינימום 24 עמודים, שדרה עם טקסט מ-79 עמודים, עמודים כפולה של 2.

## שדרה
`עובי שדרה = מספר עמודים × עובי עמוד` (ראו טבלת הניירות). הוסיפו לוחות/קיפולים בכריכה קשה. הדפוס יאשר את המספר האחרון — הכינו את הכריכה אחרי נעילת מספר העמודים.

## Gutter מינימלי (לפי מספר עמודים, KDP)
עד 150: 9.5 מ״מ · 151–300: 12.7 · 301–500: 15.9 · 501–700: 19.1 · 701+: 22.2.

## צבע וגופנים
- עיצוב RGB כברירת מחדל; הדפוס ממיר ל-CMYK. לבקשה מפורשת של PDF/X — להמיר בכלי ייעודי (Acrobat Preflight, Ghostscript) — סופר־ספר מייצא PDF איכותי עם גופנים משובצים אך לא מבצע המרת פרופיל צבע.
- שחור הטקסט: K100 (לא רב־ערוצי). הדפוס מטפל בהמרה.
- גופנים: משובצים (נכון ל-PDF שהופק).

## רשימת בדיקה לפני שליחה לדפוס
- [ ] כל הפרקים קיימים, מספור עמודים רציף.
- [ ] מספר העמודים כפולה של 4 (אופסט).
- [ ] זכויות יוצרים, ISBN, שנה נכונים.
- [ ] תוכן עניינים תואם.
- [ ] תמונות ≥ 300 DPI (או הוחלט אחרת).
- [ ] כריכה: bleed, שדרה לפי מספר עמודים סופי, אזור ברקוד.
- [ ] שוליים בטוחים 5–6 מ״מ לטקסט.
- [ ] הגהה אחרי עימוד נקייה.
- [ ] הדפסת ניסיון (proof) לפני הדפסת כמות.
